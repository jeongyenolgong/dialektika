# 디알렉티카

기아 OU 워크숍 2회차 게임의 화면입니다. 개발 중입니다.

- **참가자** `p1-identity.html` — 폰
- **진행자** `host.html` — 노트북 한 대
- **스크린** `screen-01-entry.html` — 프로젝터

## 지금 어디까지 되어 있나

진행자 화면의 **「다음」 한 번이 모든 기기를 같이 움직입니다.** 장부는 `bus.js` 한 곳에 있고,
적히는 것은 「다음」을 몇 번 눌렀나 하나뿐입니다.

**수집·문장·투표 같은 내용은 아직 오가지 않습니다.** 화면마다 혼자 흉내 내는 숫자입니다.

## 장부를 어디에 두나 — 스스로 고릅니다

| | 언제 | 무엇 |
|---|---|---|
| **인터넷 중계** | 그냥 링크로 열었을 때 | 각자 어디서 접속하든 됩니다. 와이파이를 같이 쓰지 않아도 되고 LTE여도 됩니다 |
| **노트북** | `server.py`가 켜져 있을 때 | 인터넷이 없어도 돕니다. **워크숍 당일에 쓰는 길입니다.** 폰이 노트북과 같은 와이파이여야 합니다 |
| **혼자** | 둘 다 닿지 않을 때 | 브라우저 한 대 안에서만 |

### 노트북을 장부로 쓰려면

```
python3 server.py
```

켜지면 폰으로 들어올 주소가 화면에 뜹니다. 이 창을 닫으면 꺼집니다.

### 판을 나누려면

주소 끝에 `?room=` 을 붙이면 그 이름끼리만 같은 판이 됩니다. 예: `host.html?room=test2`
