# 디알렉티카

기아 OU 워크숍 2회차 게임의 화면입니다. 개발 중입니다.

- **참가자** `p1-identity.html` — 폰
- **진행자** `host.html` — 노트북 한 대
- **스크린** `screen-01-entry.html` — 프로젝터

## 지금 어디까지 되어 있나

진행자 화면의 **「다음」 한 번이 모든 기기를 같이 움직입니다.** 장부는 `bus.js` 한 곳에 있습니다.

**수집한 쌍·문장·투표가 실제로 오갑니다.** 폰이 모은 것을 진행자 화면이 받아 적고,
스크린과 다른 폰이 그 숫자를 같이 봅니다.

## 2026.08.14에 바뀐 것

### 수집이 세 걸음이 됐습니다

```
코드 입력  →  포스터에서 찾은 단어 입력  →  반대말·비슷한 말 입력
```

**코드를 넣어도 단어를 보여주지 않습니다.** 포스터를 실제로 읽은 사람만 넘어갑니다.
포스터 30장은 단어를 낱말퍼즐 격자에 숨긴 판이라, 찾아내는 데 시간이 듭니다.

대조는 관대합니다 — **띄어쓰기를 무시하고 자모 하나 차이는 통과**시킵니다.
재는 것이 철자 실력이 아니라 「포스터 앞에 있었는가」이기 때문입니다.
틀려도 잃는 것이 없습니다. 문구는 「다시 보세요」 하나이고 횟수 제한도 실패 기록도 없습니다.

### 힌트 — 두 번까지, 폰에만

| | |
|---|---|
| ① | **방향** — 가로 → · 세로 ↓ · 대각선 ↘ · 대각선 ↗ |
| ② | **글자 수를 네모로.** 두 어절이면 사이를 띄워 나눔까지 (`■■■　■■■`) |

버튼에 남은 개수가 붙습니다(「힌트 2개」 → 「힌트 1개」 → 꺼짐).
쓴 힌트는 지워지지 않고 쌓입니다 — 값을 치른 것이 눈에 남아 있어야 하기 때문입니다.

### 점수

**단계마다 그 단계 점수로만 순위를 매기고, 최종 발표에서만 누적합니다**(개인도 팀도).

| 단계 | 점수 |
|---|---|
| 수집 | 힌트 0회 **3점** · 1회 **2점** · 2회 **1점** |
| 창작 | 문장 한 편 **1점** *(놀공 임의 — 확정 아님)* |
| 투표 | 득표 한 표 **1점** *(놀공 임의 — 확정 아님)* |

무게는 `host.html`의 `WEIGHT`와 `p4p5-collect.html`의 `SCORE` **두 줄에만** 있습니다.
플레이 테스트 뒤에 그 줄만 갈아 끼웁니다.

### 순위 알림 — 1분마다 발표

**등수가 바뀌었을 때가 아니라 1분마다** 그때의 순위를 잽니다.
전에는 계속 1위인 사람에게 두 번 다시 안 울렸습니다.

- 모든 폰이 **같은 순간에** 울립니다(벽시계에 맞춤)
- 개인 1·2·3위 → **4.5초 뒤** 팀 1·2·3위. 알림 하나가 3.5초 머물러서 시간차를 둡니다
- **변동은 안 알립니다** — 「2위 → 1위」가 아니라 「현재 N위」만

### 화면

- **목업 조작줄과 가짜 키보드 자리를 없앴습니다.** 실제 플레이 화면에 보이면 안 되는 것들입니다
- **글자 치는 곳이 전부 진짜 입력 칸입니다** — 커서 옮기기·가운데 고치기·붙여넣기가 됩니다
- 버튼이 아닌 자리를 두드려도 **화면이 확대되지 않습니다**

> 포스터 30장을 만드는 파일(`build_review.py`·대응표·낱말 목록)은 이 저장소에 없습니다.
> 작업 폴더의 `posters/`에 있습니다.

## 장부를 어디에 두나 — 스스로 고릅니다

| | 언제 | 무엇 |
|---|---|---|
| **인터넷 중계** | 그냥 링크로 열었을 때 | 각자 어디서 접속하든 됩니다. 와이파이를 같이 쓰지 않아도 되고 LTE여도 됩니다 |
| **노트북** | `server.py`가 켜져 있을 때 | 인터넷이 없어도 돕니다. **워크숍 당일에 쓰는 길입니다.** 폰이 노트북과 같은 와이파이여야 합니다 |
| **혼자** | 둘 다 닿지 않을 때 | 브라우저 한 대 안에서만 |

### 노트북을 장부로 쓰려면

```
python3 server.py
```

켜지면 폰으로 들어올 주소가 화면에 뜹니다. 이 창을 닫으면 꺼집니다.

### 판을 나누려면

주소 끝에 `?room=` 을 붙이면 그 이름끼리만 같은 판이 됩니다. 예: `host.html?room=test2`
